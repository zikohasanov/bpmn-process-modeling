# BPMN Process Modeling

> Self-initiated portfolio case study for a fictional single-location restaurant. No real client or employment experience is represented.

The models compare a hypothesized manual phone-order process with a proposed web-request process. The point is to make handoffs, decisions, and failure outcomes visible before discussing automation.

- [As-is process](as-is.md)
- [To-be process](to-be.md)
- [Improvement rationale](improvement-notes.md)

The Mermaid flowcharts are intentionally labeled as BPMN-inspired process views. They use explicit events, tasks, gateways, and lanes where Mermaid supports a clear text representation, but they are not exported BPMN 2.0 XML and should not be presented as tool-validated BPMN models.
